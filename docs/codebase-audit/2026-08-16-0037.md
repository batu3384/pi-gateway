## CA-001 | Major | Correctness | scripts/pi/recover-readonly-root.sh

**Kanıt:** `setup-docker-ssd.sh` yalnızca `ssd-hotplug-handler.sh:79-80` ve `post-deploy.sh:195` içinde çağrılıyor; `recover-readonly-root.sh` degraded sonrası full stack restore ederken Docker SSD migrate çağırmıyor. `stack-watchdog.sh:22-24` degraded + `ssd_mount_healthy` → `recover-stack.sh` → `recover-readonly-root.sh` yolu hotplug'u bypass eder.

**Neden:** Degraded modda `setup-docker-fallback.sh` `data-root` → `/var/lib/docker` yapar. SSD geri gelince watchdog/health recover symlink'i SSD'ye alır ama Docker SD'de kalabilir — `ENABLE_DOCKER_SSD=true` iken imajlar SSD'de beklerken daemon SD root kullanır; tutarsız state, gereksiz SD doluluğu, restore gecikmesi.

**Yön:** `recover-readonly-root.sh` içinde `ssd_mount_healthy` + `ENABLE_DOCKER_SSD=true` iken `setup-docker-ssd.sh` çağır (hotplug ile aynı gate). Contract test ekle (watchdog restore yolu).

## Adversarial Review (SSD algoritması)

**Scope:** `ssd-alive.sh`, `ssd-health.sh`, `ssd-hotplug-handler.sh`, `recover-readonly-root.sh`, `setup-docker-ssd.sh`, `setup-docker-fallback.sh`, `stack-health.sh`, `ensure-data-symlink.sh`

**Verdict:** **CONCERNS** (CA-001 iki persona tarafından Critical'e terfi — merge öncesi fix)

### Critical (terfi)

- **Docker SSD restore gap (CA-001):** Saboteur — watchdog recover SSD symlink düzeltir, Docker SD'de kalır, compose "healthy" görünür ama layer/cache split. Security Auditor — degraded ephemeral SD data + docker root mismatch veri tutarlılığı riski.

### Warnings

- Degraded süresince `repair_fallback_sd` ephemeral marker; Syncthing/n8n yazıları SSD'ye gitmez (tasarım ama veri kaybı penceresi).
- `SSD_USB_XHCI_REBIND=false` default — tam bus dropout yazılımla kurtarılamaz (dokümante, kabul edilmiş tavan).
- Rate-limit 3/900s sonrası reboot yalnızca `SSD_USB_RESET_REBOOT=true` — varsayılan false, uzun outage.

### Notes

- `flock` symlink lock + soft-reset lock iyi.
- `fsync` probe JMicron false-green için doğru.
- `test-adversarial-fixes.sh` C1–C11 kontratları güçlü; Docker SSD restore yolu test dışı.

### Summary

Algoritma çekirdeği (probe → merdiven → degraded → hotplug restore) sağlam ve iyi testlenmiş. **Tek ciddi delik:** `ENABLE_DOCKER_SSD=true` sonrası watchdog/health recover yolu Docker'ı SSD'ye geri taşımıyor. Fix + dokümantasyon güncellemesi merge öncesi şart.
