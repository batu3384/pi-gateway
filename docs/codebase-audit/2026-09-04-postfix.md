# Pi Gateway post-fix audit — 2026-09-04

## Sonuç

Kod, deploy contract’ları, Pi stack ve Mac DNS kontrolleri geçti. SSD üzerinde
offline `e2fsck -f -y` dört forced pass çalıştı; her pass yeni ext4 metadata
bozulması bulup düzeltti. Bu nedenle USB bridge/SSD/enerji zinciri donanım
sağlığı hâlâ **BLOCKER**.

### Donanım blocker

Kernel geçmişinde aynı olay zinciri mevcut:

- USB disconnect ve enumeration `-71` / `-110`
- `device offline error`
- `Buffer I/O error`
- `JBD2` checksum/journal abort
- ext4 read-only remount

Fsck pass’lerinde sırasıyla yeni inode checksum, `^@`/bozuk first entry ve
directory checksum hataları tekrarlandı. Daha fazla `-y` pass çalıştırılmamalı.
Önerilen fiziksel sıra: powered USB hub/uygun güç, kısa kaliteli kablo, farklı
USB 3 port/bridge, sonra SMART ve medya testi; backup doğrulanmadan disk
değişimi yapılmamalı.
